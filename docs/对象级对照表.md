# QLExpress4 → QlExpress Rust 对象级对照表（验收清单）

基线：`alibaba/QLExpress` **4.2.0-beta**（`com.alibaba.qlexpress4`），共 **237 个 Java 类**。
本文档与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，本表回答"**每个 Java 对象落在哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case，参数名与 Java 一致
2. **每个 `.rs` 文件只对应一个 Java 对象**；保留 Java 对象身份并转换为
   snake_case（`CallInstruction` → `call_instruction.rs`），避免与同模块其他类合并
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. `lib.rs` 只做 crate 门面（`pub mod` + 顶层 `pub use` re-export），**禁止堆放对象**
5. Java 多层嵌套包只要求**最后一层目录**完全对齐
   （如 `runtime/instruction/` → `runtime/instruction/`）
6. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责、与 Java 实现的差异
7. jackson → serde；`java.lang.reflect` → `NativeRegistry` + `#[derive(QLExpressType)]`；
   `Class.forName` → 显式注册表 + `ClassSupplier` trait
