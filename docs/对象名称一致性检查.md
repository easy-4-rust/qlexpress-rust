## 二、命名检查口径

1. Java 类型名保持 PascalCase，Rust 文件使用 snake_case。
2. Java 子包至少对齐最后一级目录，例如
   `runtime.data.lambda.QLambdaMethod` →
   `runtime/data/lambda/qlambda_method.rs`。
3. `mod.rs` 只声明模块和重导出；`lib.rs` 只提供 crate 门面。
4. 一个 Java 对象只对应一个职责文件；Rust 原生适配对象另建文件，不挤入
   Java 对象文件。
5. 缩写按项目既有公共 API 保留，不使用机械转换制造错误名称。

## 九、验收边界

本检查确认仓库内对象结构、源码职责、测试和静态质量门禁。Java 反射与
JDK Proxy 在 Rust 中采用注册表和显式闭包，这是有测试的等价职责实现，
不是 JVM 二进制兼容。真实业务数据、宿主类型注册、线上容量、部署编排和
外部可观测系统仍需在具体生产环境执行验收，不能由仓库测试替代。
